# MacroGrid

Simple command button mod for Minecraft 26.1+ (Fabric).


##  How to Build

1. Open a terminal/console in the project folder.
2. Run the command:
   * **Windows:** `gradlew build`
   * **Linux/Mac:** `./gradlew build`
3. The compiled `.jar` file will be in: `build/libs/`

## Requirements
To run the mod in-game, you need:
* Fabric API
* owo-lib
